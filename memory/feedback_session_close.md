---
name: Session zárási protokoll
description: Session végén mindig frissíteni kell a fejlesztesi_naplo.md-t az elvégzett munkával
type: feedback
---

Session lezárásakor kötelező frissíteni a `fejlesztesi_naplo.md` fájlt az alábbi tartalommal:
- Új `### DÁTUM - Cím` szekció az elvégzett munkával
- Minden új funkció / bugfix röviden felsorolva
- Technikai tanulságok ha volt valami nem triviális
- Aktuális cache verzió (`app.js?vX`)
- TODO lista frissítése (elvégzett feladatok kipipálva)

**Why:** A user ezt kérte explicit szabályként — a napló a projekt kontextusát adja minden új sessionhöz, ha nincs frissítve, elvész a tudás.

**How to apply:** Ha a user "zárjuk a sessiont" vagy hasonlót mond, ELŐSZÖR frissítsd a `fejlesztesi_naplo.md`-t, AZTÁN nyugtázd a zárást. Ne várj arra hogy a user emlékeztessen.
