---
name: Git workflow preference
description: User kezeli a git commitokat manuálisan, ne ajánlj fel commit-ot
type: feedback
---

Ne ajánlj fel `git commit`-ot a munka után. A user manuálisan commital, ha és amikor akar.

**Why:** A user nem ismeri a git terminológiát és saját maga kezeli a verziótörténetet session végén.

**How to apply:** Módosítás után ne kérdezd meg "szeretnéd commitolni?" — egyszerűen kérdezz a tesztelésről vagy a következő feladatról.
